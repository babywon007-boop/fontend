DATABASE DESIGN & ARCHITECTURE

โครงสร้างความสัมพันธ์ฐานข้อมูล (ER Model)

การออกแบบฐานข้อมูลสำหรับ บริษัท ทริป ทัวร์ เที่ยว จำกัด เพื่อรองรับระบบสารสนเทศด้านการท่องเที่ยวไทยอย่างเป็นระบบ ประกอบด้วย 5 ตารางหลักที่มีความสัมพันธ์กันตามหลักฐานข้อมูลเชิงสัมพันธ์ (Relational Database: TA1_Pv, TA1_Tv, TA1_Tourist, TA1_Activity, TA1_Hotel)

แผนผังความสัมพันธ์ (Entity-Relationship Diagram)

แสดง Primary Key (PK) และ Foreign Key (FK) ที่เชื่อมโยงระหว่างทั้ง 5 ตาราง

TA1_Pv 11 rows
  • Pv_Id PK, INT
  • Pv_Name VARCHAR(100)
TA1_Tv 5 rows
  • Tv_Id PK, INT
  • Tv_Name VARCHAR(100)
TA1_Tourist 12 rows
  • Tourist_Id PK, INT
  • Tourist_Name VARCHAR(150)
  • Pv_Id FK -> TA1_Pv
  • Tv_Id FK -> TA1_Tv
TA1_Hotel 9 rows
  • Hotel_Id PK, INT
  • Hotel_Name VARCHAR(150)
  • Pv_Id FK -> TA1_Pv
  • Hotel_Rating DECIMAL(2,1)
TA1_Activity 12 rows
  • Act_Id PK, INT
  • Act_Name VARCHAR(150)
  • Act_Participant_Name VARCHAR(150)
  • Act_Price DECIMAL(10,2)
  • Tourist_Id FK -> TA1_Tourist
1. TA1_Pv ➔ TA1_Tourist

ความสัมพันธ์แบบ 1:N (หนึ่งจังหวัดมีสถานที่ท่องเที่ยวได้หลายแห่ง)

2. TA1_Tv ➔ TA1_Tourist

ความสัมพันธ์แบบ 1:N (หนึ่งรูปแบบการเดินทางใช้เดินทางไปได้หลายสถานที่)

3. TA1_Tourist ➔ TA1_Activity

ความสัมพันธ์แบบ 1:N (หนึ่งสถานที่ท่องเที่ยวมีกิจกรรมได้หลายรายการ)

4. TA1_Pv ➔ TA1_Hotel

ความสัมพันธ์แบบ 1:N (หนึ่งจังหวัดมีโรงแรมที่พักได้หลายแห่ง)

พจนานุกรมข้อมูล (Data Dictionary)

คำอธิบายโครงสร้างฟิลด์ ชนิดข้อมูล และข้อกำหนดของทั้ง 5 ตาราง

1. ตาราง TA1_Pv (จังหวัด)

ชื่อฟิลด์ ชนิดข้อมูล คีย์ คำอธิบาย
Pv_Id INT Primary Key รหัสระบุจังหวัด เช่น 10 (กทม.), 20 (ชลบุรี)
Pv_Name VARCHAR(100) - ชื่อจังหวัด เช่น กรุงเทพมหานคร, ชลบุรี, เชียงใหม่

2. ตาราง TA1_Tv (การเดินทาง)

ชื่อฟิลด์ ชนิดข้อมูล คีย์ คำอธิบาย
Tv_Id INT Primary Key รหัสยานพาหนะ เช่น 111 (รถยนต์), 252 (รถไฟ)
Tv_Name VARCHAR(100) - ประเภทการเดินทาง เช่น รถยนต์ส่วนตัว, รถทัวร์, เครื่องบิน

3. ตาราง TA1_Tourist (สถานที่ท่องเที่ยว)

ชื่อฟิลด์ ชนิดข้อมูล คีย์ คำอธิบาย
Tourist_Id INT Primary Key รหัสสถานที่ท่องเที่ยว (1-12)
Tourist_Name VARCHAR(150) - ชื่อสถานที่ท่องเที่ยว เช่น หาดบางแสน, วัดพระแก้ว
Pv_Id INT Foreign Key รหัสจังหวัด เชื่อมโยง TA1_Pv (Pv_Id)
Tv_Id INT Foreign Key รหัสยานพาหนะ เชื่อมโยง TA1_Tv (Tv_Id)

4. ตาราง TA1_Activity (กิจกรรม)

ชื่อฟิลด์ ชนิดข้อมูล คีย์ คำอธิบาย
Act_Id INT Primary Key รหัสกิจกรรม (301-312)
Act_Name VARCHAR(150) - ชื่อกิจกรรม เช่น ดำน้ำตื้น, ปั่นจักรยานริมโขง
Act_Participant_Name VARCHAR(150) - ชื่อผู้เข้าร่วมกิจกรรม หรือผู้รับผิดชอบ
Act_Price DECIMAL(10,2) - ราคาค่ากิจกรรม (บาท) 0 = ฟรี
Tourist_Id INT Foreign Key รหัสสถานที่ท่องเที่ยว เชื่อมโยง TA1_Tourist (Tourist_Id)

5. ตาราง TA1_Hotel (โรงแรม/ที่พัก)

ชื่อฟิลด์ ชนิดข้อมูล คีย์ คำอธิบาย
Hotel_Id INT Primary Key รหัสโรงแรม (201-209)
Hotel_Name VARCHAR(150) - ชื่อโรงแรม เช่น บีชรีสอร์ทบางแสน
Pv_Id INT Foreign Key รหัสจังหวัด เชื่อมโยง TA1_Pv (Pv_Id)
Hotel_Rating DECIMAL(2,1) - คะแนนประเมินโรงแรม (ช่วง 1.0 ถึง 5.0)
บริษัท ทริป ทัวร์ เที่ยว จำกัด (Trip Tour Tiew Co., Ltd.) เอกสารความสัมพันธ์ฐานข้อมูลท่องเที่ยว 5 ตาราง: TA1_Pv, TA1_Tv, TA1_Tourist, TA1_Activity, TA1_Hotel
